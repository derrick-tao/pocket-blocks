Privacy & local storage

Updated 14 November 2026. Maintained by derrick-tao.

On this device

The game stores the best score in pocket-blocks-best and the landing-outline, celebration, and touch-control choices in pocket-blocks-options using this browser’s localStorage. Sound starts off on each visit. Downloaded game, icon, and privacy files are cached for offline play. An in-progress board is not saved. Browser clearing, private-mode restrictions, or storage eviction can remove this data.

Network and hosting

The app requests its own game files and checks for updates. It does not upload scores or gameplay, create accounts, request names or location, or include ads, analytics, tracking pixels, or external runtime assets. Sounds are synthesized locally.

GitHub Pages hosts this game. GitHub states that visitors’ IP addresses are logged and stored for security, even when visitors are not signed in. See GitHub Pages’ disclosure and GitHub’s privacy statement. These external pages need internet; this notice and the game work offline after downloading.

Families and contact

Parents or guardians can contact the maintainer through the repository issue tracker or public profile. Do not post children’s names, identifiers, contact details, or other personal information in public issues. Children should ask a parent or guardian to contact the maintainer.

This is a description of current behavior, not legal certification. Children’s privacy obligations and hosting terms need review before child-directed promotion or adding accounts, analytics, advertising, or sharing.

Controls and limits

Change visual and touch-control options in Game options. No gesture path or touch history is stored or uploaded. Clear this site’s browser data to remove scores, preferences, and offline files. Other project sites on the same github.io origin share browser storage; a dedicated origin is a future isolation improvement. Zoom restrictions request a fixed mobile scale, but browser/OS accessibility controls may override it.
